# 文書處理工具

PEICD100 開發的 Windows 11 x64 文書、PDF、圖片與影音工具。

## v1.7.0 正式版下載與安裝

到 [最新正式版](https://github.com/peicd100/documents-toolkit-releases/releases/latest) 或 [v1.7.0](https://github.com/peicd100/documents-toolkit-releases/releases/tag/v1.7.0) 手動下載。與原 v1.7.0 測試版使用相同安裝程式及 ZIP，已安裝 v1.7.0 不需重裝；更新摘要與正式通道資訊同步修正。

- `SHA256SUMS.txt`：下載檔案的 SHA-256 校驗碼。

### 實驗選項與已知限制

在「螢幕錄影」勾選「單視窗遠端可見控制列（實驗）」，使用點選視窗／拖曳矩形模式，但**只能單擊唯一視窗**，不能拖矩形或選整個螢幕；不符合會明示停止，沒有偷偷切換擷取來源。控制列及四條窄邊框維持一般不排除視窗，不呼叫全域取消排除；其他模式維持原排除保護。遠端實驗只接受不透明、偶數尺寸影格，尺寸／來源身分改變或查詢失效即安全收尾，不裁切、補黑、遮罩或反覆隱藏控制列。

**尚未完成整合後的實際應用／Parsec互動驗收，也不提供完整全螢幕相容保證。** 先前生成單視窗候選通過不代表任意應用已支援。背景合成驗證不等於原生layered視窗／affinity查詢、實機像素排除、全域快捷鍵或真實音源已驗收。

來源工作流整批測試曾在 PDF ToolWorker 的 Qt 建構發生原生存取違規，原因尚未定位；個別案例及本輪必要回歸通過不當作根因修復。本次將相同成品改列正式更新，不代表該問題已修復，請保留原檔並先用非重要檔案驗證；單視窗功能仍維持預設關閉的實驗選項。

## 使用方式

持久設定變更自動保存：勾選／選單立即處理，文字在完成輸入或短暫停頓後保存，不需按套用。無效輸入、寫入失敗或快捷鍵占用會明示原因並保留原設定；保存設定不會自動開始工作或觸發權限提升。進行中的工作固定使用起始設定，新偏好下次生效。影音檢視器也會記住音量／靜音、速度、比例、跳轉秒數及存幀命名；音軌／字幕等依目前檔案的選擇不當作跨檔案偏好。

所有文書工具共用固定的來源、輸出與開始／停止位置；底部操作列會依字體及內容調整高度，避免按鈕被裁切。「詳細紀錄」展開後，即使沒有紀錄也會顯示「尚無處理紀錄」，清除後維持展開。適用工具支援多選、追加去重、移除、拖入與一至六列清單；人工裁切逐張調整，各張保留自己的範圍。功能分類可搜尋，進階設定的收合狀態會記憶。

「輸出至來源資料夾」為全域持續模式，成功、清空、切換工具或重啟都不取消。批次檔案可來自不同資料夾，各自輸出回來源旁邊；PDF／圖片合併等需要共同輸出的工具，跨資料夾時會請你選擇目的地，取消則不開始。取消勾選來源模式才恢復該工具上次手動選擇的位置。

處理成功後會自動清空來源與選取項目。失敗或停止後保留來源，方便重試。輸出到來源旁邊時，會避開來源的同名檔案。

## 截圖、手動長截圖與錄影

螢幕名稱只是顯示標籤，不作為原生裝置名稱比對依據；選定目標的位置、DPI 與實際預覽尺寸必須唯一吻合。游標不在任何螢幕、配置改變或對應歧義時停止，不自動改抓主螢幕。若有同名螢幕且無法唯一識別指定目標，請選「游標所在螢幕」，開始前把游標移到目標螢幕。具體失敗原因同時顯示在通知、工具頁及診斷紀錄；未操作日常桌面的限制仍適用。

主工具選單提供「截圖」、「長截圖」及「螢幕錄影」三頁，保留原有 16 個工具；模式、螢幕、放大鏡、輸出及錄影設定直接在主頁操作，不再開啟大型浮動工具箱。設定自動記住，不再有套用／取消變更。三頁只共用輸出位置並立即同步，命名／子資料夾及模式、放大鏡、FPS／音源各自保留。舊版不同目的地依截圖、長圖、錄影順序取第一個非空已存位置，不依時間猜測；可隨時在任一頁修改共同位置。底部開始／停止與進度固定，小視窗可捲動設定內容。從頁面開始後主視窗僅最小化，工作列仍可還原；取消選區回原頁與原最大化狀態，成功不搶焦點，需要處理的失敗才還原。系統匣亦可啟動擷取或回到設定頁。

按擷取快捷鍵或頁面開始後，滑鼠所指視窗會保持亮色，其餘區域變暗。**單擊高亮視窗，或拖曳矩形並放開，就直接執行**；不再拉邊調整或按 Enter。Esc 或右鍵取消。放大鏡可設 2／4／8／16 倍，也可在選取時用滾輪調整；顯示實際像素與十字參考線，倍率不改變成品尺寸。只處理單一螢幕，不跨螢幕拼接；視窗同名無法唯一綁定、已失效或移出螢幕時，會明示重新選取，不盲猜其他視窗。

**一般截圖直接裁切選區預覽的同一份原始像素**，不再把連續擷取來源的第一張影格當成截圖結果。完成後自動安全儲存原尺寸 PNG，並複製實際圖片到剪貼簿；兩項分別回報結果，不開結果視窗或搶走焦點。任一失敗仍保留圖片，可回工具頁重試；不覆寫既有檔案，輸出子資料夾及工具名稱前綴可設定。純黑但不透明的合法內容不會一律被判為錯誤。

長截圖仍由使用者自行向下捲動，程式不注入輸入或自動捲動。穩定後才比對重疊並去重；低信心時暫停追加、保留已確認內容。主頁可暫停／繼續、撤銷上一段、查看上一張底端與目前候選頂端的縮圖並指定重疊像素補拍。來源失效時保留已拼接內容供完成存檔，不盲接。快捷鍵停止／完成後自動存 PNG 及複製圖片；達安全大小上限會提示先完成，不默默縮圖或拆圖。

錄影選取完成即依已存設定啟動；**整個單一螢幕模式按開始或啟動快捷鍵後會直接擷取／錄製，不再詢問範圍**。預設 30 FPS、可選 60 FPS，以軟體 H.264／AAC 輸出 MP4；一般模式的奇數寬高僅補黑邊至偶數，不拉伸；上述單視窗遠端實驗則拒絕奇數尺寸，不補黑邊。首次音源預設無聲，可明確選系統聲音、預設麥克風或混音；啟動程式或取消選區不會自行開麥，音源失效不偷偷改成別的來源。

錄影與長圖共用小控制列，固定於選定螢幕可用區上緣中央，不可拖曳、不恢復舊座標。錄影提供暫停／繼續、停止儲存及有效時長；長圖顯示段數／高度，可暫停、撤回上一段及停止儲存。四條窄範圍邊框滑鼠穿透，暫停仍可見並改變樣式，整螢幕選取時也留在螢幕內。一般模式要求各個窄邊框及控制列成功設定、回讀排除旗標；遠端實驗改為只查新建輔助視窗維持一般 affinity=0，查詢失敗同樣停止；能力失效即明示停止並安全收尾，不靠隱藏常駐列冒充成功。**原生 API 回報成功仍不等於實際像素排除已驗證**，相容性限制見下段。完成直接安全存檔，不開結果窗。錄製中禁止更新重啟，離開先確認並收尾；未完成暫存不冒充成功成品。

各頁「快捷鍵」區在每列 Shift 前提供「停用／啟用」按鈕，只切換該動作並保留原自訂組合；重新啟用須先成功註冊，失敗或儲存失敗明示且保持原狀，不提交其他列尚未完成的修改。原本無組合不偷偷套用預設。其餘以 Shift／Ctrl／Alt 勾選及限高、可搜尋／滾動的主鍵選單操作，顯示組合與實際註冊／占用狀態，變更合法組合自動保存，也可還原預設。預設 **Ctrl+Alt+Shift+S 單張截圖、Ctrl+Alt+Shift+R 錄影開始／停止、Ctrl+Alt+Shift+L 長圖開始／停止**；同工作選區中再次按即取消，工作中再次按即停止儲存，存檔時忽略重複，不會中斷另一種擷取。**Ctrl+Alt+Shift+X 通用停止／完成、Ctrl+Alt+Shift+P 暫停／繼續**保留為工作中註冊的備用控制。衝突保留原有效設定；舊自訂組合不重設，若與新增長圖預設重複則先停用新鍵，請自行選擇。選單關閉時滾輪不會誤改主鍵；工作中不可更改控制快捷鍵，其他偏好仍可保存給下次使用。

本版以合成影格／聲音、離屏 UI 與背景發行包驗證，**未擷取日常桌面、未開啟真實麥克風或系統聲音錄製**。既有影音驗證會建立自有靜音輸出工作階段與進行唯讀健康查詢，不調整 Windows 音量或裝置設定。實體螢幕／DPI、視窗捕捉、輔助視窗排除、全域快捷鍵與 WASAPI 錄音相容性尚未互動驗收；背景通過不等於上述實機驗收。

## PDF 轉 PNG

預設 600 DPI，提供 300、600、900、1200 DPI，移除誤稱「原畫質」的 72 DPI。舊 0 值會遷移為 600，合法既有設定保留。介面顯示預估像素尺寸；提高 DPI 會增加處理時間與檔案大小，不會補回原 PDF 缺失的細節。「圖片轉 PDF」仍保留原始像素，不受此調整影響。

## Windows 11 原生右鍵

v1.3.2 改用同一產品內的兩個獨立原生套件，各自只註冊一個命令，取代 v1.3.1 仍會重複分組的同套件多 Application 方案。設計為「壓縮成 tar.gz」單一直接命令（無子選單），以及「文書處理工具」子選單；工具子選單不再包含 tar.gz，主程式內的壓縮功能保留。不相容格式、資料夾或混合選取不會顯示不適用的文書工具。「文書處理工具」子選單依副檔名及多選能力提供對應功能；除合併影片聲道、影片裁切裁剪外可直接帶入工具，不自動開始。常駐程式透過 IPC 追加去重；忙碌時延後載入，不中斷既有工作。影音檢視使用播放清單切換多個檔案。

更新後在背景檢查右鍵註冊，需要時提供非阻擋的「完成右鍵設定／稍後」，可從設定重開。設定流程不必重新安裝整包，會同時檢查兩個原生套件的版本及註冊。若只有部分設定成功，會保留已成功元件及有效程式連結，顯示錯誤並可重試修復，不自動降版或移除共享信任。首次憑證信任另行選擇並可能顯示 UAC；未同意時不變更信任，也不會擅自重新啟動 Explorer。

## 壓縮成 tar.gz

主工具新增「壓縮成 tar.gz」，可把同一個上層資料夾內的檔案與資料夾合併壓縮，支援進度、停止與輸出設定。完成前會重新讀取壓縮檔驗證內容；不覆寫來源或既有同名成品，失敗或停止不會把未完成檔案當成成功結果。

安裝版可勾選原生右鍵安裝／接管選項，在 Windows 11 檔案總管多選後啟動獨立進度視窗，不必先開主工具。此選項預設不勾選；勾選會接管既有同身分的獨立 tar.gz 右鍵套件。首次憑證信任是另外的選項，可能需要系統管理員授權；未勾選時不會擅自變更右鍵或憑證信任。可攜 ZIP 本身不註冊右鍵。

v1.3.2 使用背景、離屏、原生 COM 命令契約與隔離安裝驗證；Explorer、UAC 與實際 MSIX 升級／卸載未做互動驗收；背景與離屏測試不代表上述實機行為已驗證。安裝程式未使用商業程式碼簽章憑證，Windows 可能顯示未知發布者。

## 圖片轉 PDF

「A4 自動縮放」會顯示「保留原始像素，依 A4 版面縮放」，隱藏 DPI 選單。切換「依圖片比例」可選 DPI，切回 A4 再切回來會保留原本選擇。DPI 用於換算頁面尺寸，不增加圖片細節。

## 影音檢視工具

開啟「影音檢視工具」，或在音檔、影片上按右鍵選擇以「文書處理工具」開啟。它有獨立視窗，不影響主工具正在進行的工作。

v1.1.5 改善首次啟動與程式常駐時的開檔回應。直接開影音時先顯示播放器；需要文書功能時，再從系統匣選擇「開啟工具」。影片自動播放減少首幀等待，暫停開啟與逐幀仍保留精確定位。

切換耳機或 Windows 預設音訊輸出時，播放器會自動重新連接；裝置連線失效時也會嘗試恢復。重連保留播放位置、播放／暫停、速度、音量與靜音，不必重新開啟檔案。暫時沒有可用的耳機或喇叭時會顯示提示，裝置變更後再自動嘗試；連續失敗的重試次數有限。

在「更多設定」可選擇「音訊輸出」，預設跟隨系統；指定裝置離線時保留選擇，連線後再恢復。按「修復音訊」可重新建立連線與播放器，保留播放進度及播放／暫停狀態。背景檢查會綜合解碼資料及 Windows 音訊工作階段資訊，採有限次自動恢復；不調整 Windows 音量或靜音。

| 快捷鍵 | 功能 |
|---|---|
| ← / → | 往前／往後指定秒數，預設 5 秒，可自行調整 |
| `<` 或 `,` | 影片上一幀，自動暫停 |
| `>` 或 `.` | 影片下一幀，自動暫停 |
| 空白鍵 | 播放／暫停 |
| F11 / 雙擊畫面 | 全螢幕；Esc 返回 |
| Ctrl+O | 開啟音檔或影片 |
| Ctrl+S | 儲存當前幀為原始解析度 PNG |

音檔支援 MP3、WAV、M4A、AAC、FLAC，以及只有音訊的 MP4。依檔案實際內容自動切換，帶封面的音檔仍使用音訊模式。波形會在背景產生，產生期間可先播放；可點擊或拖曳波形定位。波形快取會檢查內容雜湊，長音檔採固定大小的波形資料。

支援播放進度、時間跳轉、音量、靜音、播放速度、音軌及字幕選擇，並可載入 SRT／WebVTT 字幕。存幀會保留影片及目前位置；檔名含時間，連續儲存不會覆寫先前圖片。

音訊輸出未啟動或裝置失效時會自動重連；必要時重建播放器，保留播放位置、播放／暫停、倍速、音量、靜音及音軌字幕。重試有次數上限，不會因正常無聲片段而重啟，也不會調整 Windows 音量。

點擊進度條可直接跳到該位置，滑鼠懸停會顯示時間，也可拖曳定位。一般秒數、指定時間與進度條跳轉皆維持原本的播放／暫停狀態；拖曳時先暫停，放開後恢復原狀態。上一幀／下一幀會先暫停，方便檢視。

兩種模式的播放、前後跳轉與音量控制維持相同位置；音檔會收起逐幀、存幀、畫面比例與字幕等影片專用控制。影片模式保留逐幀、存幀及全螢幕。「更多設定」預設收合，展開後可調整跳轉秒數、指定時間、速度、畫面比例、音軌字幕及存幀位置。

安裝版會註冊上述五種音檔與原有影片格式的「開啟方式」選項，不會強制更改預設播放器。若要設為預設播放器，可按播放器內的「預設影音應用程式」，再由 Windows 設定選擇。

## 更新與設定

「自動檢查並下載更新」預設開啟，每次啟動及每小時在背景檢查、下載新版並驗證大小與 SHA-256。更新狀態直接顯示在原本按鈕上：檢查中、下載中、重新啟動以更新；不跳出確認視窗。下載完成後等待使用者按「重新啟動以更新」，才會自動關閉、在目前位置靜默安裝並重新開啟，保留設定。

取消勾選後，可按「檢查更新」手動檢查，再按「下載更新 v版本號」下載；既有關閉選擇會保留。已下載的更新不會自行安裝或強制重新啟動。工作進行中會停用重啟按鈕，工作完成後恢復；尚未處理的來源清單不會保留。失敗時在原按鈕位置提示重試，詳細原因顯示於提示文字。可攜版使用程式內更新時，也會由安裝程式在目前資料夾完成更新。

首次從舊版升級到 v1.1.4 時仍使用目前版本的更新流程；升級完成後才適用以上新流程。

主視窗右上角「設定」提供「自動檢查並下載更新」及「登入 Windows 後自動啟動」。v1.0.2 起，首次正常啟動／新安裝預設開啟登入自動啟動，登入 Windows 時只常駐系統匣。取消勾選即可停用，選擇會保存，重新啟動或升級不會強制恢復；不需要系統管理員權限。可攜版搬移位置後，請重新勾選以更新路徑。

設定與啟動紀錄放在 `%LOCALAPPDATA%\DocumentsToolkit`。解除安裝預設保留這些設定。PPT 轉 PDF 功能需要電腦上安裝 Microsoft PowerPoint。
