# 文書處理工具

PEICD100 開發的 Windows 11 x64 文書、PDF、圖片與影音工具。

## 下載與安裝

到 [Releases](https://github.com/peicd100/documents-toolkit-releases/releases/latest) 下載：

- `DocumentsToolkit_Setup_v1.0.3.exe`：一般使用者建議使用的安裝版。安裝在目前使用者的目錄，可從 Windows「已安裝的應用程式」解除安裝。
- `DocumentsToolkit_Windows11_x64_v1.0.3.zip`：可攜版。完整解壓後啟動「文書處理工具.exe」，請保留旁邊的 `_internal` 資料夾。
- `SHA256SUMS.txt`：下載檔案的 SHA-256 校驗碼。

## 使用方式

所有文書工具共用固定的來源、輸出與開始／停止位置。勾選「來源資料夾」可將檔案輸出在來源旁邊；只有全部來源位於同一個直接上層資料夾時可使用。取消勾選、清空來源或加入不同資料夾的檔案後，會恢復該工具上次手動選擇的位置。

處理成功後會自動清空來源與選取項目。失敗或停止後保留來源，方便重試。輸出到來源旁邊時，會避開來源的同名檔案。

## 影片檢視工具

開啟「影片檢視工具」，或在影片上按右鍵選擇以「文書處理工具」開啟。它有獨立視窗，不影響主工具正在進行的工作。

| 快捷鍵 | 功能 |
|---|---|
| ← / → | 往前／往後指定秒數，預設 5 秒，可自行調整 |
| `<` 或 `,` | 上一幀，自動暫停 |
| `>` 或 `.` | 下一幀，自動暫停 |
| 空白鍵 | 播放／暫停 |
| F11 / 雙擊畫面 | 全螢幕；Esc 返回 |
| Ctrl+O | 開啟影片 |
| Ctrl+S | 儲存當前幀為原始解析度 PNG |

支援播放進度、時間跳轉、音量、靜音、播放速度、音軌及字幕選擇，並可載入 SRT／WebVTT 字幕。存幀會保留影片及目前位置；檔名含時間，連續儲存不會覆寫先前圖片。

點擊進度條可直接跳到該位置，滑鼠懸停會顯示時間，也可拖曳定位。一般秒數、指定時間與進度條跳轉皆維持原本的播放／暫停狀態；拖曳時先暫停，放開後恢復原狀態。上一幀／下一幀會先暫停，方便檢視。

底部固定保留常用播放、前後跳轉、逐幀、存幀、音量及全螢幕控制。「更多設定」預設收合，展開後可調整跳轉秒數、指定時間、速度、畫面比例、音軌字幕及存幀位置。

安裝版會註冊影片「開啟檔案」選項。若要設為預設播放器，可按播放器內的「預設影片應用程式」，再由 Windows 設定選擇。

## 更新與設定

啟動時可在背景檢查新版，也可按「檢查更新」。下載及安裝前均會詢問；工作進行中會延後安裝。更新檔案會檢查大小與 SHA-256，升級保留設定。

主視窗右上角「設定」提供「自動檢查更新」及「登入 Windows 後自動啟動」。v1.0.2 起，首次正常啟動／新安裝預設開啟登入自動啟動，登入 Windows 時只常駐系統匣。取消勾選即可停用，選擇會保存，重新啟動或升級不會強制恢復；不需要系統管理員權限。可攜版搬移位置後，請重新勾選以更新路徑。

設定與啟動紀錄放在 `%LOCALAPPDATA%\DocumentsToolkit`。解除安裝預設保留這些設定。PPT 轉 PDF 功能需要電腦上安裝 Microsoft PowerPoint。
